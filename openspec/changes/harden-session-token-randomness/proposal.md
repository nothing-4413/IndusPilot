# Change: 强化会话 Token 随机性

## Why

当前会话 Token 使用用户名、时间戳和自增计数器拼接生成，容易泄露用户身份并降低猜测成本。生产级身份边界需要不可预测、不包含业务身份信息的会话令牌。

## What Changes

- 将会话 Token 生成改为 256-bit 随机值，并以十六进制编码返回。
- 移除 Token 中的用户名、时间戳和自增计数器信息。
- 补充基础测试，验证 Token 格式、长度、不泄露用户名，并且连续登录生成不同 Token。

## Non-Goals

- 不改变会话 TTL、Redis session 存储或权限模型。
- 不实现刷新令牌、登录失败锁定或设备绑定。
