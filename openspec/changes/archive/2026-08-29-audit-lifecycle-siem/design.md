# Design: 保留窗口、归档与安全 SIEM 投递

常规 `events` 查询在配置了 `retention_days` 时自动附加下限，避免日常列表无限增长。完整性校验和归档读取完整的升序链记录，因此保留窗口既不删除数据，也不改变哈希链验证结果。

归档端点返回筛选后的完整 CSV，并在生成响应后写入一条独立的 `operation-audit.archive` 审计事件。该动作沿用既有 `audit:export` 权限。

SIEM sink 在审计记录已落库后由分离线程尽力投递。它对 URL、允许主机和 DNS 返回地址应用与 webhook 通知相同的边界：只接受 HTTP(S)、拒绝用户信息、要求主机精确列入允许名单、拒绝任何私有或保留 DNS 地址，并使用验证过的 IP 地址连接且保留原始 Host header。HTTPS 不会降低证书验证；无法满足其证书/SNI 要求时投递失败而审计写入继续成功。
