# Change: 强化 HTTP 结构化日志

## Why

HTTP 请求日志当前通过字符串拼接生成 JSON。请求追踪编号、路径和用户名都可能包含引号、反斜杠或换行，导致日志行不是合法 JSON，并允许用户输入污染后续日志解析。

## What Changes

- 使用 JSON 序列化器生成 HTTP 请求日志，确保所有用户可控字段正确转义。
- 保持现有日志字段、追踪编号和 stdout 输出位置兼容。
- 增加回归测试，验证恶意字符不会破坏单行 JSON 日志。

## Non-Goals

- 本次不引入新的日志后端或日志采集系统。
- 本次不改变请求日志字段语义或认证、审计协议。
