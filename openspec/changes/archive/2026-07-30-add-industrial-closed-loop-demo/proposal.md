## Why

项目已经具备资产、监控、告警、AI 诊断、工单和审计能力，但缺少一条面向评审和 GitHub 展示的可复现端到端演示路径。需要用脚本把模块串成工业运维闭环，降低本地体验成本。

## What Changes

- 新增工业告警到工单闭环 PowerShell 演示脚本。
- 新增演示文档，说明场景、前置条件、运行命令和输出文件。
- README 增加端到端演示入口。
- 脚本输出健康检查、资产、运行状态、告警、通知、AI 诊断、工单和审计导出结果。

## Impact

- 影响模块：demo、docs。
- 兼容性：不改变后端业务行为；脚本默认使用内存仓储和本地默认账号。
