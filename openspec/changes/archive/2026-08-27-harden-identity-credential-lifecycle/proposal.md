# Change: 收紧身份凭据生命周期边界

## Why

当前身份模块可以验证密码和创建会话，但用户仓储没有密码更新能力，生产部署只能手工替换数据库中的演示哈希。密码策略也没有进入配置和 HTTP 契约，导致密码轮换无法作为可审计、可渐进接入的正式能力。

## What Changes

- 增加可配置的最小密码长度和 PBKDF2-SHA256 迭代次数，并在启动配置校验时拒绝不安全值。
- 为用户仓储增加更新密码哈希的接口，内存和 MySQL 实现保持一致。
- 增加认证后的密码轮换服务和 HTTP 入口，只接受当前密码与新密码，不记录任一明文密码。
- 新密码使用随机盐生成版本化 PBKDF2-SHA256 哈希；保留旧格式只用于兼容现有本地演示账号。
- 密码轮换成功或失败都写入操作审计，但审计内容只包含用户和结果，不包含密码或哈希。
- 增加基础单测、HTTP smoke 和部署文档，明确会话撤销、外部身份提供商和分布式限流不在本 change 内。

## Non-Goals

- 不在本 change 内实现所有会话全量撤销或 refresh token。
- 不实现外部 OAuth/OIDC/LDAP 身份提供商。
- 不把单进程登录失败锁定伪装成跨副本限流；分布式限流另立 change。
